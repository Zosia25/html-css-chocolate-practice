# html-css-chocolate-practice

Self-paced practice repository for building a chocolate brand website from a Figma design using HTML and CSS.

# Про курс: Основи веб-розробки

Цей курс пропонує всебічне знайомство зі світом веб-розробки, зосереджуючись на
таких ключових темах, як **HTML**, **CSS** та **оптимізація продуктивності**
веб-сайтів.

### Чого ви навчитеся:

- **Ролі та інструменти:** Розуміння обов'язків сучасного розробника та робота з
  актуальним стеком технологій.
- **HTML5 & CSS3:** Фундаментальні техніки розмітки та стилізації для створення
  адаптивних веб-додатків.
- **Продуктивність:** Глибоке розуміння рендерингу сторінок та методів
  оптимізації швидкодії веб-додатків.

### Результат:

До завершення навчання ви опануєте навички створення візуально привабливих
інтерфейсів та навчитеся значно покращувати досвід користувачів (UX) завдяки
оптимізації технічних показників проєктів.

## Структура заняття:

- Підготовка проекту до роботи
- Структурна розмітка сторінки
- Верстка секції Hero та Benefits
- Верстка секції Ingredients та Made
- Верстка секції Products
- Верстка секції Bestsellers та Reviews

## Технічне завдання:

- HTML-файл називається `index.html`
- У корені проєкту є папка `images` із зображеннями
- У назвах файлів відсутня кирилиця, пробіли. Назви містять тільки літери, числа
  і слова англійською мовою
- Вихідний код відформатований за допомогою `Prettier`
- Всі зображення та текстовий контент взяті з макету
